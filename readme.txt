PREVIEW

PUBLISH WITH GITHUB PAGES
1. Go to https://github.com/new and create a public repository named mousumi-birthday.
2. Extract this ZIP on your computer.
3. Upload index.html and the whole assets folder to the repository root.
4. Click Commit changes.
5. Open Settings -> Pages.
6. Select Deploy from a branch, branch main, folder /(root), then Save.
7. Wait for GitHub Pages to publish and show the actual URL, usually https://YOUR-USERNAME.github.io/mousumi-birthday/
8. Open the URL GitHub shows and test it on your phone. It is not live until you complete these steps.
